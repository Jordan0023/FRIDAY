Publication threshold

What earns a place here

  1. Reachability: the attack path is available without valid administrator credentials.
  2. Attribution: the attacker-controlled input is tied to the fault or execution sink.
  3. Reproduction: the security effect repeats with a benign differential control.
  4. Novelty: a dated public-record review finds no matching disclosure or fix.
  5. Caveat: public novelty cannot exclude a private, embargoed, or reserved duplicate.
